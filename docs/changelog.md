## 2026-09-03 — SPIKE-09: native Rust FFI (ffmpeg-next) cho core lib Tauri tương lai — ĐẠT, có caveat

Dựng thật `tools/spike-09/` (crate Rust độc lập, `ffmpeg-next` + FFmpeg 7.1.1 qua `vcpkg`) trên máy Windows 11 thật, cài đủ 3 việc `tsmc-ingest` CLI cần (remux copy-video + encode-audio AAC + faststart, thumbnail JPEG, rút subtitle `.srt`). Kết quả: 72.1x realtime (file mẫu tổng hợp, không phải file thật baseline 40.8x), 6 DLL ~21.2 MB, build crate 14.2s (toolchain vcpkg/LLVM đã có sẵn từ trước, chưa đo chi phí cài máy sạch). **Phát hiện quan trọng hơn số liệu:** một lỗi tầm thường (buffer audio sai số kênh) làm `avcodec_send_frame()` segfault thẳng tiến trình thay vì trả `Result::Err` — rủi ro loại khác hẳn shell-out CLI hiện tại (lỗi tương đương ở đó chỉ làm tiến trình con thoát mã lỗi, CLI cha vẫn sống). Quyết định GUI Tauri vẫn để ngỏ; điều kiện áp dụng nếu chọn hướng native FFI ghi ở [ADR-0013 § Cập nhật 2026-09-03](./adr/0013-bot-dong-hanh-va-pipeline-ingest.md#cập-nhật-sau-khi-accepted-2026-09-03-spike-09--native-rust-ffi-cho-core-lib-tauri-tương-lai).
